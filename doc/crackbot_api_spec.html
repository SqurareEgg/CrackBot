1
인증 /auth
로그인, 토큰 갱신, 로그아웃. JWT Access(15분) + Refresh(7일) 방식.
2
건축물 /buildings
점검 대상 건축물 등록, 조회, 수정.
3
점검 프로젝트 /projects
점검 프로젝트 및 구역 CRUD. 진행률 집계 포함.
4
사진/탐지 /photos, /detections
사진 업로드(S3 Pre-signed URL), AI 탐지 결과 조회, 안전 등급 조회.
5
보고서 /reports
보고서 생성 요청(비동기), 상태 조회, 다운로드 URL 발급.

인증 API — /auth
POST/auth/login로그인 (이메일/비밀번호)▼
Request Body
{ "email": "inspector@company.com", "password": "password123!" }
필드타입필수설명
emailstring필수RFC 5321 이메일 형식
passwordstring필수최소 8자
Response
200access_token, refresh_token, user 정보 반환
401이메일 또는 비밀번호 불일치
{ "data": { "access_token": "eyJhbGci...", "refresh_token": "eyJhbGci...", "token_type": "Bearer", "expires_in": 900, "user": { "id": "uuid", "email": "inspector@company.com", "name": "김민준", "role": "inspector" } } }
POST/auth/refreshAccess Token 갱신▼
Request Body
{ "refresh_token": "eyJhbGci..." }
200새 access_token 반환
401refresh_token 만료 또는 폐기됨
POST/auth/logout로그아웃 (토큰 폐기)JWT 필요▼
refresh_token을 DB에서 폐기(is_revoked=true). 이후 해당 토큰으로 갱신 불가.
204로그아웃 성공 (No Content)
GET/auth/me내 프로필 조회JWT 필요▼
200id, email, name, role, is_active 반환
건축물 API — /buildings
GET/buildings건축물 목록 조회JWT 필요▼
파라미터타입필수설명
qstring선택건물명 또는 주소 검색어
pageinteger선택기본값 1
sizeinteger선택기본값 20, 최대 100
200건축물 배열 + pagination 정보
POST/buildings건축물 등록JWT 필요▼
Request Body
{ "name": "강남 논현동 상가건물", "address": "서울 강남구 논현동 123-4", "latitude": 37.5172, "longitude": 127.0286, "floors": 6, "built_year": 1998 }
필드타입필수설명
namestring필수건물명 (최대 200자)
addressstring필수도로명 주소
latitudefloat선택위도 좌표
longitudefloat선택경도 좌표
floorsinteger선택건물 층수
built_yearinteger선택사용승인 연도
201등록된 건축물 객체 반환
GET/buildings/{building_id}건축물 상세 조회JWT 필요▼
200건축물 상세 + 연결된 프로젝트 수
404건축물 없음
PATCH/buildings/{building_id}건축물 정보 수정 (Partial Update)JWT 필요▼
수정할 필드만 포함. name, address, floors, built_year 수정 가능.
200수정된 건축물 객체 반환
점검 프로젝트 API — /projects
GET/projects프로젝트 목록 조회JWT 필요▼
파라미터타입필수설명
statusstring선택planned / in_progress / completed
building_iduuid선택특정 건축물의 프로젝트만 조회
pageinteger선택기본값 1
sizeinteger선택기본값 20
200프로젝트 배열 (진행률, 결함 수 포함)
POST/projects프로젝트 생성JWT 필요▼
Request Body
{ "building_id": "uuid", "title": "논현동 상가 외벽 정기점검", "start_date": "2026-03-20", "end_date": "2026-03-28", "zones": [ { "zone_name": "A구역", "floor": 1 }, { "zone_name": "B구역", "floor": 2 } ] }
필드타입필수설명
building_iduuid필수대상 건축물 ID
titlestring필수프로젝트 제목
start_datedate필수점검 시작일 (YYYY-MM-DD)
end_datedate선택종료 예정일
zonesarray선택구역 목록 (최대 10개)
201생성된 프로젝트 + 구역 목록 반환
GET/projects/{project_id}프로젝트 상세 조회JWT 필요▼
200프로젝트 + 구역 목록 + 전체 안전등급 + 진행률
404프로젝트 없음
PATCH/projects/{project_id}/status프로젝트 상태 변경JWT 필요▼
Request Body
{ "status": "completed" }
200상태 변경된 프로젝트 반환
사진 업로드 — /zones/{zone_id}/photos
POST/zones/{zone_id}/photos/upload-urlS3 Pre-signed Upload URL 발급JWT 필요▼
Request Body
{ "filename": "IMG_0023.jpg", "content_type": "image/jpeg", "latitude": 37.5172, "longitude": 127.0286, "taken_at": "2026-03-25T09:41:00Z" }
Response 200
{ "data": { "photo_id": "uuid", "upload_url": "https://s3.amazonaws.com/...", "expires_in": 300 } }
200Pre-signed URL 반환. 클라이언트는 이 URL로 직접 S3에 PUT 요청
POST/photos/{photo_id}/analyzeAI 결함 탐지 요청JWT 필요▼
S3 업로드 완료 후 앱에서 호출. Celery 작업 큐에 YOLOv8 분석 작업을 등록하고 즉시 202 반환.
202분석 작업 접수됨. task_id 반환
{ "data": { "task_id": "celery-uuid", "status": "queued" } }
GET/photos/{photo_id}/detections탐지 결과 조회JWT 필요▼
Response 200
{ "data": { "photo_id": "uuid", "is_analyzed": true, "detections": [ { "id": "uuid", "defect_type": "crack", "confidence": 0.88, "bbox": { "x": 120, "y": 80, "w": 240, "h": 60 }, "crack_width_mm": 0.4, "severity": "high" } ], "overlay_url": "https://cdn.crackbot.ai/..." } }
200탐지 결과 목록 + 오버레이 이미지 URL
404사진 없음
안전 등급 — /grades
GET/projects/{project_id}/grades프로젝트 전체 안전 등급 조회JWT 필요▼
Response 200
{ "data": { "overall_grade": "D", "max_crack_mm": 0.4, "total_defects": 10, "recommendation": "A구역 1층 외벽 균열 0.4mm 기준치 초과. 긴급 보수 필요.", "zones": [ { "zone_id": "uuid", "zone_name": "A구역", "grade": "D" }, { "zone_id": "uuid", "zone_name": "B구역", "grade": "C" } ] } }
보고서 API — /reports
POST/reports보고서 생성 요청 (비동기)JWT 필요▼
Request Body
{ "project_id": "uuid", "template_type": "standard", "format": "both" }
필드타입필수설명
project_iduuid필수보고서 생성 대상 프로젝트
template_typeenum필수standard(국토안전관리원) / summary(간이)
formatenum필수pdf / docx / both
Response 202
{ "data": { "report_id": "uuid", "status": "pending", "message": "보고서 생성이 시작되었습니다. 완료 시 푸시 알림을 발송합니다." } }
GET/reports/{report_id}/status보고서 생성 상태 조회JWT 필요▼
Response 200
{ "data": { "report_id": "uuid", "status": "completed", "format": "both", "generated_at": "2026-03-25T09:55:00Z" } }
200pending / processing / completed / failed 중 현재 상태
GET/reports/{report_id}/download보고서 다운로드 URL 발급JWT 필요▼
Query Params
파라미터타입필수설명
file_typestring필수pdf 또는 docx
Response 200
{ "data": { "download_url": "https://cdn.crackbot.ai/reports/...", "expires_in": 604800, "file_type": "pdf" } }
200S3 Pre-signed URL (7일 유효)
400보고서 생성 미완료 상태
GET/reports보고서 목록 조회JWT 필요▼
파라미터타입필수설명
project_iduuid선택특정 프로젝트의 보고서만 조회
statusstring선택pending / processing / completed / failed
pageinteger선택기본값 1
200보고서 목록 배열 (status, 생성일, 형식 포함)
