## Phase 2: 보고서 실제 파일 생성 + 다운로드 ✅ 완료

현재 문제: `_generate_report()` 백그라운드 태스크가 가짜 S3 키만 저장하고 `generate_report_files()` 를 호출하지 않음.
다운로드 URL이 존재하지 않는 `/v1/mock-download/` 엔드포인트를 반환.

- [x] **[BE] reports.py** — `_generate_report()` 내부에서 `generate_report_files()` 실제 호출.
       예외 발생시 `failed` 상태로 전환
- [x] **[BE] report_generator.py** — `ParagraphStyle()` fontName 중복 인자 버그 수정
       (`fontName=font` 하드코딩 → `kw.setdefault('fontName', font)` 로 변경)
- [x] **[BE] reports.py** — `GET /v1/reports/{id}/download-file` 엔드포인트 추가 (FileResponse)
- [x] **[BE] reports.py** — `GET /v1/reports/{id}/download` — 로컬 파일 경로로 download_url 변경
       (`/v1/reports/{id}/download-file?file_type={type}`)
